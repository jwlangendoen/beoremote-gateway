No button received?

Turn on your TV. On the Beoremote, open LIST → LIGHT and press a function. If it arrives in the app, no TV menu changes are needed.

If nothing arrives, select the gateway on your Horizon:

  1. Open MENU → Settings.
  2. Highlight Service Menu and press the red button before the centre button.
  3. Open Customer Service Menu → Settings → BeoLink Gateway.
  4. Select Home Assistant Gateway and confirm with the centre button.

If the gateway is missing, choose your TV in this app, then reopen the TV's gateway list.

Rename LIGHT functions on the remote
  1. Open LIST → Settings → Advanced → Products. Show or add the separate Beovision (infrared/IR) profile.
  2. Select that Beovision product at the top of LIST.
  3. Open Settings → Advanced → Light menu → Rename. Show and Move control visibility and order.
  4. Switch back to your Bluetooth-paired Horizon.

Keep your Horizon pairing. Names on the remote and in this app are set separately.

Connection settings

To change the name in the TV menu, use Name in the TV menu in the app's optional Configuration settings.

Automations and advanced setup

Each button uses a normal Home Assistant automation. Open it in Home Assistant for any action or condition. Changes made there stay there; this app won't overwrite them.

Disable any older automation for the same button to avoid running both.
