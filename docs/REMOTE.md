# Rename the LIGHT functions

On the Horizon, the name editor is hidden in a separate infrared product profile
on the Beoremote One BT. You only need to do this if you want your own display names.

1. Open **LIST → Settings → Advanced → Products**. Show or add the separate
   **Beovision (infrared/IR)** profile. If there is a **Show** menu, enable it there.
2. Select that **Beovision** profile from the product name at the top of LIST.
3. Open **Settings → Advanced → Light menu**.
4. Use **Rename** for names such as Movie or All off. **Show** controls which
   functions are visible; **Move** changes their order.
5. Switch back to your usual Bluetooth-paired Horizon product through LIST.

Keep your Horizon pairing. The extra IR profile gives you access to the editor;
the renamed functions are also available on the Horizon profile afterwards.
Choose the matching Home Assistant scene in the app separately.

Menu wording can vary by remote firmware. Sources:
[B&O: show an IR product](https://support.bang-olufsen.com/hc/en-us/articles/360045510351-How-do-I-set-up-Beoremote-One-for-use-with-Beosound-Moment),
[B&O: switch products](https://support.bang-olufsen.com/hc/en-us/articles/360041313292-How-do-I-switch-between-products-using-my-Beoremote-One),
